
# Customer Segmentation – Power BI Dashboard

## Project Overview

This project analyzes customer shopping behavior using Power BI. 
The objective is to understand customer purchasing patterns, spending behavior, 
payment preferences, product category performance, and purchase frequency.

The dashboard provides an interactive view of customer data and helps identify 
important trends that can support data-driven business decisions.

## Tools Used
- Power BI
- Power Query
- DAX
- Microsoft Excel

## Key KPIs
- Total Purchase Amount: 996.38K
- Total Customers: 3.9K
- Subscription Status
- Customer Purchase Frequency

## Dashboard Analysis
The dashboard analyzes:
- Purchase Amount by Gender
- Purchase Amount by Payment Method
- Purchase Amount by Product Category
- Customer Purchase Frequency
- Seasonal Shopping Trends
- Customer Location
- Customer Gender
- Subscription Status

## Dashboard Filters
The dashboard includes interactive filters for:
- Gender
- Season
- Category
- Location

## Key Business Questions
1. Which product categories generate the highest purchase amount?
2. Which payment method is most commonly associated with purchases?
3. How does purchasing behavior differ between male and female customers?
4. Which customers have higher purchase frequency?
5. How does customer spending vary across different seasons?
6. Which locations contribute significantly to customer purchases?
7. How does subscription status relate to customer purchasing behavior?

## Key Insights
- Clothing and Accessories are among the major contributors to purchase amount.
- Customer purchases are distributed across multiple payment methods.
- Purchase behavior varies between customer groups and genders.
- Monthly, weekly, and fortnightly customers show different purchase frequencies.
- Seasonal and category-level analysis helps identify customer shopping patterns.

## Project Workflow
1. Collected the customer shopping dataset.
2. Cleaned and transformed the data using Power Query.
3. Created calculated measures using DAX.
4. Built interactive Power BI visualizations.
5. Added slicers for customer segmentation.
6. Analyzed customer purchasing behavior.
7. Created the final interactive dashboard.
